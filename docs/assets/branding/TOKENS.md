# Moyu design tokens

Source: [`src/index.css`](../../../src/index.css). Colors are application tokens; these values are not a separate theme.

| Token | Light | Dark |
|---|---|---|
| Background | `#eff8ff` | `#0b111e` |
| Foreground | `#09090b` | `#f8fafc` |
| Card | `#ffffff` | `#151f32` |
| Border | `#09090b` | `#334155` |
| Primary | `#38a8f8` | `#38a8f8` |

The application imports Plus Jakarta Sans Variable, with fallback fonts; see the font license in [third-party notices](../../../THIRD_PARTY_NOTICES.md). Card radius is `1rem`, control and chip radius are `999px`, and sheet radius is `1.25rem`.
